# LankaFresh Frontend

React + TypeScript + Vite SPA. See the root [README.md](../README.md) for
setup and run instructions, and [CONTRIBUTING.md](../CONTRIBUTING.md) for
the branching workflow.

Work inside your module's folder under `src/features/`. Shared UI goes in
`src/components/`, shared API setup in `src/services/api.ts`, and shared
types in `src/types/` (module-specific types stay in a `types.ts` file
inside your own feature folder).
